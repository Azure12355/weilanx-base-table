Up and running in a minute.

Works with VS Code 1.90 or later, plus Cursor and other VS Code based editors.

  1. Download the .vsix

    Grab the latest build from GitHub Releases, or package it yourself:

    npm install && npm run package

  2. Install from VSIX

    Open the Extensions panel, click the ··· menu and choose Install from VSIX. Or use the CLI:

    code --install-extension weilanx-base-table.vsix --force

  3. Open or create a .base file

    Double-click any .base file, or run "Create Base Table" from the Command Palette. The sidebar lists every table in your workspace.
